# 本地文件工作台 Demo

这是供后端联调使用的单页演示，无前端框架、无 CDN、无需构建。HTML、CSS、浏览器协议客户端和页面交互分别维护。

在项目根目录运行：

```powershell
npm run demo
```

1. 打开终端输出的页面地址，默认 `http://127.0.0.1:4173`。
2. 点击“连接服务”，输入同一终端显示的一次性配对码并配对。
3. 输入绝对目录路径，点击“授权并打开”；Windows 下也可用系统选择器。
4. 点击目录逐级浏览，点击文本文件打开编辑器。新建操作作用于当前浏览目录；重命名与删除作用于最近点击的文件或目录，确认框会显示完整相对路径。
5. 保存通过读取时的版本校验。外部变更会触发事件；冲突时保留编辑内容，可先复制草稿再重新读取。

配对凭据仅在当前页面内存中存活，不写入浏览器存储、URL 或事件记录。刷新页面会丢失凭据，需要重启服务取得新配对码。断线重连可复用同一页面的凭据，目录需重新授权。未保存内容在普通断线时保留；授权撤销时清空。

CRLF 文件保存时恢复 CRLF，UTF-8 BOM 原样回传。浏览器文本框不能保留每行混合换行，所以混合换行和独立 CR 文件只读展示。页面不会渲染或执行读入的 HTML、SVG 或脚本。

可使用 `.env` 或环境变量调整端口：

```dotenv
LOCAL_FOLDER_PORT=8765
DEMO_PORT=4173
```

两个端口都可设为 `0` 自动分配，页面从 `/config.json` 获取实际 WebSocket 地址。`npm run demo` 为本次后端进程加入准确的 demo 来源，普通后端启动方式保持扩展来源校验规则。页面不能直接通过 `file://` 使用。

按 `Ctrl+C` 关闭页面服务和后端。该 demo 用于本机开发验证；Chrome/Firefox 扩展来源、CSP 和连接行为仍需在目标扩展中单独验收。
