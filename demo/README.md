# 本地文件工作台 Demo

这是供后端联调使用的 Vue 3 单页前端，使用 Vite 构建，依赖通过 npm 安装。页面按功能拆分为 Vue 单文件组件；业务状态放在 composable，WebSocket 客户端独立维护。

在项目根目录运行：

```powershell
npm install
npm run demo
```

该命令以开发模式同时启动 Vite 页面服务和后端，无需预先构建。修改 `demo/src/` 中的 Vue、JavaScript 或 CSS 后，页面自动热更新；修改后端 `src/`、Demo 服务代码或 `demo/vite.config.ts` 后，服务自动重启。修改 `.env` 后需要手动重启命令。

后端自动重启会断开当前连接并结束目录授权，需要重新连接服务并通过系统选择器授权目录；页面凭据丢失时，使用终端最新输出的配对码。端口设为 `0` 时，重启后的地址可能变化，请打开最新页面地址。

需要预览构建产物时，先执行 `npm run demo:build`，再执行 `npm run demo:serve`。该预览模式不监听源码变化。

1. 打开终端输出的页面地址，默认 `http://127.0.0.1:4173`。
2. 点击顶部“连接与配对”打开弹窗，连接服务后输入同一终端显示的一次性配对码并配对。顶部“请求与实时事件”另开一个弹窗查看日志。弹窗可用关闭按钮、Esc 或点击背景关闭。
3. 在顶部 header 点击“选择文件夹”，通过 Windows 系统文件夹选择器授权目录；取消选择会保留当前目录。当前路径在 header 中展示，长路径悬停可查看全文。“最近目录”以下拉面板展示和移除记录，重新打开须使用系统选择器。选择器不可用时显示错误并保留当前工作区。
4. 目录以树形展示，使用文件夹、文件和链接图标区分类型。点击目录展开或收起，子目录按需加载、独立分页；编辑器顶部的“刷新”同步已展开分支，保留尚未同步的编辑内容。点击文本文件打开编辑器。右键文件或目录打开操作菜单，也可聚焦后按 Shift+F10；搜索结果支持相同操作。目录菜单提供“新建文件 / 新建目录”，文件和子目录菜单提供“重命名 / 删除”，操作始终作用于右键目标，确认框显示完整相对路径。根目录仅提供新建操作，不能重命名或删除。操作影响当前编辑文件时，尚未同步的修改须确认放弃；操作其他项目时保留草稿。
5. 编辑器不提供“保存”和“重新读取”按钮。停止输入约 250 毫秒后自动写入本地，连续输入合并请求，中文输入法在组合结束后写入；写入期间可继续输入，后续修改串行同步。切换文件或目录授权前先完成待写入内容。本地文件变更通过监听自动更新网页，底部显示同步状态。写入携带读取版本；并发冲突时暂停自动写入并保留网页内容，可选择“使用本地内容”或确认后“使用网页内容”。写入或读取失败保留草稿并提供“重试同步”，断线取消待写入任务。
6. 点击 header 的“隐藏与停止监听规则”打开独立弹窗，编辑后点击“应用规则”。规则反馈在弹窗内显示，关闭后保留当前编辑内容。

文件工作区占满页面剩余高度，不显示页面滚动条。长目录和文件内容可在各自区域内滚动，滚动条保持隐藏。

目录树与编辑区之间的分隔线支持左右拖动调整宽度，目录树最窄 180px，编辑区至少保留 280px。双击分隔线恢复默认宽度；Tab 聚焦分隔线后可用左右方向键微调，Shift 加速，Home/End 调整到最窄/最宽。窄屏继续使用上下布局。

配对凭据仅在当前页面内存中存活，不写入浏览器存储、URL 或事件记录。刷新页面会丢失凭据，需要重启服务取得新配对码。断线重连可复用同一页面的凭据，目录需重新授权。未保存内容在普通断线时保留；授权撤销时清空。

编辑区域使用 MIT 开源的 [CodeMirror 6](https://codemirror.net/)，提供行号、按文件名按需加载的语法高亮、撤销/重做、括号匹配、代码折叠和搜索替换（Ctrl/Cmd+F），Tab 缩进。切换文件时重置撤销历史；本地同步更新不触发重复保存，并尽量保留光标与滚动位置。编辑器保持紧凑字体并随工作区高度调整。

CRLF 文件保存时恢复 CRLF，UTF-8 BOM 原样回传。当前同步层将换行统一为 LF 供编辑器显示，因此混合换行和独立 CR 文件仍只读展示。页面不会渲染或执行读入的 HTML、SVG 或脚本。

可直接修改项目根目录的 `.env` 调整端口，启动时会自动加载，也可通过进程环境变量覆盖：

```dotenv
LOCAL_FOLDER_PORT=8765
DEMO_PORT=4173
```

两个端口都可设为 `0` 自动分配，页面从 `/config.json` 获取实际 WebSocket 地址。`npm run demo` 为本次后端进程加入准确的 demo 来源，普通后端启动方式保持扩展来源校验规则。页面不能直接通过 `file://` 使用。

按 `Ctrl+C` 关闭页面服务和后端。该 demo 用于本机开发验证；Chrome/Firefox 扩展来源、CSP 和连接行为仍需在目标扩展中单独验收。

```text
demo/
  index.ts / server.ts       联调启动命令、开发热更新和构建产物服务
  index.html / vite.config.ts
  src/
    main.js / App.vue        Vue 应用入口和页面组装
    components/              各功能面板
    editor/code-editor.js    CodeMirror 实例、语言加载与编辑事务适配
    composables/useFolderWorkspace.js  状态与业务交互
    services/folder-client.js          WebSocket 协议客户端
    assets/styles.css        页面样式
  dist/                      Vite 构建产物（忽略提交）
```
